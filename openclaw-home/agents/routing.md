# Routing Rules

默认模型：

- 复杂分析和复杂代码：`openai-codex/gpt-5.5`
- 搜索：必须走内网 SearXNG
- 本地文件操作：必须走本地 skill 或本地节点

任务路由：

- 用户要求搜索互联网、查询最新资料、查官方文档、比较产品或排障资料时，调用 SearXNG 搜索。
- 用户要求复杂代码、架构设计、大项目重构、Kubernetes/Longhorn 排障时，使用 `openai-codex/gpt-5.5` 分析。
- 用户要求整理本地文件、移动文件、重命名文件、读取本地路径时，使用本地文件 skill；如果本地节点不可用，说明当前无法访问本地电脑。
- 用户要求分析敏感文件、微信目录、密钥、私有聊天记录时，默认拒绝发送给云端模型，除非用户明确授权。
- 用户只是问简单概念、短文本改写、普通建议时，可以直接回答，不必搜索。

搜索规则：

- 搜索引擎使用 `SEARXNG_BASE_URL` 指向的内网 SearXNG。
- 搜索后优先总结可靠来源，必要时列出链接。
- 对时间敏感问题，需要说明检索日期。

文件规则：

- 删除操作必须二次确认。
- 清理文件时先生成计划，再执行移动或重命名。
- 默认只操作用户指定的 workspace 或授权目录。
