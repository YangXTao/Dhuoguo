# 记忆整理 Skill

这个 skill 用来保存关于用户和 OpenClaw 部署的长期知识。

以下情况需要写入长期记忆：

- 用户做出部署决策。
- 用户明确偏好或否定某个工具、模型、网络拓扑或安全策略。
- 某个问题已经解决，并且以后可能再次遇到。
- 用户说“记住”、“以后”、“默认”、“我希望”或类似表达。

记忆格式：

- 日期。
- 用户问题或决策。
- 最终结论。
- 推荐实现方式。
- 约束条件和安全规则。
- 下次遇到类似问题时应该如何回答。

不要保存：

- 密钥。
- access token。
- 密码。
- 私密聊天内容。
- 不必要的原始文件内容。
